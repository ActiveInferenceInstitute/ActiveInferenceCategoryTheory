# Repository layout

`ActiveInferenceInstitute/ActiveInferenceCategoryTheory` contains an authored
curriculum, supporting Markdown/YAML/CFF/JSON metadata, and executable Python/Bash
validation gates. It is not an installable application package. This page maps
the tracked tree.

## Source versus generated

Authored curriculum, metadata, and Python/Bash gate sources are maintained in
place. Generated documents have named producers:

- [`arm-runtimes.md`](arm-runtimes.md) is generated by
  [`../.github/scripts/measure_arms.py`](../.github/scripts/measure_arms.py) via
  `./run.sh measure`. Never edit its numbers by hand; refresh it.
- `.aii/README.md`, `.aii/AGENTS.md`, `.aii/docs/README.md`,
  `.aii/docs/AGENTS.md`, and `.aii/docs/INTEGRATION.md` are rewritten by
  InstituteOS sidecar tooling.

The hand-authored `gnn/learner_perception_model.md` is validated against the
deliberate installed parser by `./run.sh gnn`; it is not rendered from code.
The separate `setup` arm provisions that parser. Hermetic gate regressions do
not qualify model semantics, parser origin, or education-bundle validity.

## Conventions

- One H1 per document; use H2 and H3 for structure.
- Relative Markdown targets must remain within the repository and be tracked
  files or directories with tracked descendants. Symlink dependencies must
  also be admitted; mere local existence is insufficient. The
  [documentation gate](validation.md) enforces these rules.
- Every tracked Markdown document must be listed in
  [`documentation-index.md`](documentation-index.md); the same gate enforces it.
- Keep the "adventure mode" voice of the syllabus when editing curriculum text.
- Prefer plain Markdown and avoid trailing whitespace.
