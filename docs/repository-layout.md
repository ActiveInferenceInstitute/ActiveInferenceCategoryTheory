# Repository layout

`ActiveInferenceInstitute/ActiveInferenceCategoryTheory` is a documentation-only
repository: it ships a curriculum and its supporting metadata, with no package,
no build, and no runtime. This page maps the tracked tree.

## Source versus generated

Most of the tree is hand-maintained: every Markdown, YAML, and CFF file is
written and reviewed by a person. Two exceptions have a named producer:

- [`arm-runtimes.md`](arm-runtimes.md) is generated by
  [`../.github/scripts/measure_arms.py`](../.github/scripts/measure_arms.py) via
  `./run.sh measure`. Never edit its numbers by hand; refresh it.
- `.aii/README.md`, `.aii/AGENTS.md`, `.aii/docs/README.md`,
  `.aii/docs/AGENTS.md`, and `.aii/docs/INTEGRATION.md` are rewritten by
  InstituteOS sidecar tooling.

The `gnn/learner_perception_model.md` specification is hand-written but is
*validated* against the pinned GNN parser by `./run.sh gnn`; it is not rendered
from code. There is no `output/`, `dist/`, or `build/` directory.

## Conventions

- One H1 per document; use H2 and H3 for structure.
- Every relative Markdown link must resolve inside the repository — the
  [documentation gate](validation.md) enforces this.
- Every tracked Markdown document must be listed in
  [`documentation-index.md`](documentation-index.md); the same gate enforces it.
- Keep the "adventure mode" voice of the syllabus when editing curriculum text.
- Prefer plain Markdown and avoid trailing whitespace.
